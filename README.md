# Streaming Platform MVP

This workspace contains a single full-stack streaming platform app with:

- A Next.js frontend
- An Express backend with auth, movie, watchlist, rating, and user routes
- Real public-domain movie data from Internet Archive

## Run locally

1. Install dependencies:
   - `npm install`
2. Start both apps:
   - `npm run dev`
3. Open:
   - Frontend: http://localhost:3000
   - Backend: http://localhost:4000/health
